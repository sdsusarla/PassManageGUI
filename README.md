[PassManage](https://github.com/sdsusarla/PassManage) except with a GUI created with help from Gemini CLI:

This program is a small password manager constructed out of various scripts that involves basic I/O, file handling, and basic error handling. The manager does not actually use any real encryption or hashing algorithms but uses functions I created to simulated that effect. This program was created without the aid of any AI, except for the GUI, which was constructed with the help of Gemini CLI.
